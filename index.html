Hardened principle of least privilege

👑 Super Administrator

  • ✓ Full system configuration
  • ✓ Invite/suspend staff & modify roles
  • ✓ Full provider approve/reject authority
  • ✓ Bookings and Blood SOS overrides
  • ✓ View and export immutable audit logs

🛡️ Provider Verification Officer

  • ✓ View provider verification queue
  • ✓ Access sensitive KYC documents (Audited)
  • ✓ Approve / Reject / Request changes
  • ✗ Cannot manage staff or change system settings
  • ✗ Cannot export full audit logs

💼 Operations Manager

  • ✓ Manage booking overrides & cancellations
  • ✓ Authorize payment refunds
  • ✓ Suspend non-compliant providers
  • ✓ Coordinate Blood SOS responses
  • ✗ Cannot modify employee permissions

🎧 Customer Support Specialist

  • ✓ View booking and service inquiries
  • ✓ Cancel pending bookings on customer request
  • ✗ Cannot approve or reject providers
  • ✗ Cannot view raw KYC identity documents
  • ✗ Cannot access security logs
